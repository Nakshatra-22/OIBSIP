# To-Do Web App

## Description
This project is a responsive To-Do Web Application built using HTML5, CSS3, and JavaScript. It allows users to add, edit, complete, and delete tasks while organizing them into pending and completed lists.

## Features
- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Pending and completed task counters
- Timestamps for tasks
- Data persistence using localStorage
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
