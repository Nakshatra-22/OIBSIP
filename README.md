# Vanilla JavaScript Calculator

## Description
A responsive calculator web application built using HTML, CSS, and Vanilla JavaScript. The calculator performs basic arithmetic operations with a clean and modern user interface.

## Features
- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear (C) button
- Backspace (⌫) functionality
- Division by zero error handling
- Responsive and user-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run
1. Download or clone the project.
2. Open `index.html` in any web browser.
3. Start performing calculations.

## Project Outcome
This project demonstrates JavaScript DOM manipulation, event handling, arithmetic operations, and responsive web design.
