# Tribute Page

## Description
This project is a Tribute Page dedicated to Dr. A.P.J. Abdul Kalam. It is designed using HTML5 and CSS3 to showcase his life, achievements, and inspiring quotes in a responsive and visually appealing layout.

## Features
- Responsive design
- Biography section
- Timeline of achievements
- Inspirational quote
- Clean and modern UI
- Multiple background colors and fonts

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
